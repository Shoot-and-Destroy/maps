How a mode tag is earned

A map is tagged for a mode in its .toml, and that tag is what a server reads when it picks a map. Most tags come from a match: the server played the map alone with 16 bots for ten game minutes, twice, and the map earned the mode when its land, the bots' time in the water, the deaths the map caused, the fights and the mode's objective all passed that mode's limits. The figures are on each map's page.

A few tags are the map's own: Babel and Arena come from the map's script or name, and a map named for the zombies is the zombies' whatever its match made of it. A map the next gen CTF plays is a classic CTF map too. Read the details.

A map has several uploads

The archive keeps every upload of a map: a first version and a second one, a Halloween retexture, an arena edit beside the flag map, the same map sent to aos.party twice, or once there and once to the map search. Each is a folder of its own, because a server names one, so they are separate downloads. The browser puts the maps that share a name in one card with a count: open it for each upload, its modes and its files. The switch above the results shows every folder on its own.
